4. Configure assim:

   Name:                    casino-app
   Environment:             PHP
   Region:                  US East (padrão)

      cd core && composer install --no-dev --optimize-autoloader && npm install && npm run build

   Start Command:
      cd core && php artisan migrate --force && php artisan db:seed --force && php artisan serve --host=0.0.0.0 --port=$PORT

   DB_PORT              = 3306
   DB_DATABASE          = casino
   DB_USERNAME          = [copie do MySQL]
   DB_PASSWORD          = [copie do MySQL]
   APP_ENV              = production
   APP_DEBUG            = false
   APP_URL              = https://casino-app.onrender.com
   APP_NAME             = Casino Platform
