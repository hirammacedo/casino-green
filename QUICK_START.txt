🚀 OPÇÃO 1: DOCKER (Recomendado - 3 passos)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  Inicie Docker
      $ docker compose up -d

  2️⃣  Execute as migrações
      $ docker compose exec app php artisan migrate --force

  3️⃣  Plante dados iniciais
      $ docker compose exec app php artisan db:seed --force

  ✅ PRONTO! Acesse:
     🌐 App:         http://localhost:8000
     📊 PhpMyAdmin:  http://localhost:8080
     📧 Email:       admin@casino.local
     🔑 Senha:       password

🔧 OPÇÃO 2: PHP MANUAL (Se Docker não funcionar)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  Entre na pasta
      $ cd core

  2️⃣  Instale dependências
      $ composer install
      $ npm install

  3️⃣  Configure chave
      $ php artisan key:generate

  4️⃣  Execute migrações
      $ php artisan migrate --force
      $ php artisan db:seed --force

  5️⃣  Inicie servidor (em dois terminais)
      Terminal 1: $ php artisan serve
      Terminal 2: $ npm run dev

  ✅ PRONTO! Acesse:
     🌐 App: http://localhost:8000
